# Коллизии

Для работы с коллизиями нужно создать объект на основе:

LineBody - линия, по умолчанию при столкновениях ничего не делает

RectBody - прямоугольник, по умолчанию не делает ничего при столкновениях

RectPhysicalBody - прямоугольник, по умолчанию отталкивает другие физические объекты. Можно задать массу

Если нужна своя реализация, что делать при столкновениях, то нужно создать дочерний объект, от необходимого тела, и
В одну из функций `action();` добавить свою реализацию
